# TIRAEZ shared contract v2.0.0 (for Part A)

Paste this whole file into your chat. Don't edit it by hand: it's generated by `contract/bundle.py` and checked in CI. It's the full API contract between Part A (core platform and text replies) and Part B (AI phone receptionist). Part A **implements** this API. Part B **calls** it.

The source of truth is the `contract/` folder on GitHub (alistair-dunbar/tiraez, branch `claude/cool-keller-1wzj7d`). If this file and the repo disagree, the repo wins. Changing the contract needs both partners to approve.

**What changed from v1, if you saw it:**
- Paths are now `/v2/`.
- `price_eur` became `price` plus `currency` (EUR, AED or SAR).
- `budget_eur_min` and `budget_eur_max` became `budget_min` and `budget_max`, in the agency's currency.
- Agencies now carry their market settings: country, currency, area unit, data region, time zone, voice and opening languages, and the languages each agent speaks.
- Listings gained off-plan fields.
- Two handoff topics were added: visas and residency, and investment returns.
- Viewings can now be in the evening.
- Callbacks and viewings take an optional preferred agent and language.
- Test agencies moved to `fixtures/agencies/<id>/`.
